# Security Policy

## Supported release

| Release | Status |
| --- | --- |
| 1.1.x | Supported |
| 1.0.x | Historical / superseded |

## Reporting

Please do not publish a vulnerability in a public issue before coordinated
review.

When possible, include the affected release and SHA256, component, reproduction
conditions, observed/expected behavior, and logs with secrets removed.

Never include private keys, passwords, tokens, personal data, or live secrets.

The project security model is fail-closed, append-only, SHA256-verified, and
does not allow automatic remediation, risk acceptance, or deferral.
